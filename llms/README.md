Notes and experiments about Large Language Models.

Notebooks:
- `llms/Micro_GPT.ipynb`: Small GPT-style language model experiment (see also `llms/microgpt.py`).
- `llms/explaining_logits_and_sampling.ipynb`: Toy walkthrough of logits, softmax, temperature, greedy decoding, multinomial sampling, top-k sampling, and top-p sampling.
- `llms/reinforcement_learning_for_sequence_generation.ipynb`: Reinforcement learning for sequence generation.
- `llms/useful_refs_importance_sampling_ppo_grpo.ipynb`: Useful references on importance sampling, PPO and GRPO.

Visualizations:
- `llms/visualizations/simple_transformer_shakespeare_2d_visualizer.html`: Tiny single-layer character-level transformer trained on Karpathy's tiny Shakespeare dataset with 2D character embeddings and periodic training/generated text previews.
- `llms/visualizations/micro_gpt_pyodide_visualizer.html`: Pyodide-powered (Python-in-browser) micro GPT parameter visualizer with live heatmaps and training controls.
- `llms/visualizations/micro_gpt_visualizer.html`: Micro GPT training and parameter visualizer.
- `llms/visualizations/micro_gpt_tfjs_visualizer.html`: TensorFlow.js micro GPT name-model demo.
- `llms/visualizations/micro_char_lm_torchjs_visualizer.html`: JS PyTorch-style character-level language model with 2D embeddings.
